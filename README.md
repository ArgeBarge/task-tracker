# Task Tracker

## Description

A task tracker built in react with an express.js backend and a MySQL server

## Getting Started

### Dependencies

### Installing

* Clone the repository
* Run ``` npm install ``` in ```./task-tracker```
* Run ``` npm install ``` in ```./task-tracker-backend```

### Executing program

* Run ``` mpn run start ``` in ``` ./task-tracker ```
* Run ``` npm run start ``` in ``` ./task-tracker-backend ```
