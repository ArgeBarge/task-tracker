# Task Tracker

## Description

A task tracker built in react with an express.js backend and a MySQL server

## Getting Started

### Dependencies
Ensure docker is installed
### Installing

* Clone the repository

### Executing program

* Run ``` docker compose up -d ``` in the root directory
